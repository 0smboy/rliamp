```bash
zsh ~/rliamp-veo-setup.sh install

```

### 第三步：正式演出（导演视角操作）

现在，你的赛博舞台已经搭建完毕。请**打开 Ghostty 终端**，严格按照以下顺序操作：

1. **铺设背景**： 在 Ghostty 中输入 `tmux` 进入多路复用器。 然后输入 `unimatrix -s 96 -l 'o' -c green`，让全屏下起绿色的代码雨。

2. **主角登场**： 此时代码雨正在下，按下 Tmux 的快捷键 `Ctrl+b`，然后按下键盘的 **大写 `P`** (`Shift+p`)。 此时，`rliamp` 会在一个完美的黑色方框中悬浮于屏幕正中央！

3. **开启 3D 滤镜**： 为了不打断当前画面，按下 `Cmd+T` 在 Ghostty 中新建一个标签页（Tab）。 在新标签页中输入：

   ```bash
   veo
   ```

   **切回刚才的标签页**，你会看到代码雨和 `rliamp` 已经罩上了一层 CRT 曲面和绿色辉光（静止态，方便你选歌）。

4. **开始穿梭（高潮效果）**： 在 `rliamp` 中按下空格播放音乐！ 立刻切到刚才那个新建的标签页，**再次输入**：

   ```
   veo
   ```

   **切回主画面**：Boom！整个终端现在开始发生 3D 景深拉伸、旋转和边缘重度色散，完全复刻了那个穿梭进屏幕内部的视觉效果！

5. **结束演出**： 第三次输入 `veo`，所有 3D 扭曲和发光特效瞬间消失，回归最清晰的普通文本状态。
